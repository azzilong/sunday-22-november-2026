Sunday 22 November 2026 — The World in One Page. A dense newspaper front page that sums up the day's world news in a single image: 35 stories across 7 regions — COP31 nears a final deal in Antalya, Iran strikes US bases in Bahrain, and a magnitude 6.7 quake shakes Peru lead the page, with 10 pictured stories, a numbered world map, 22 more briefs, and a DATE CHECK box that says plainly what was left out and what was not yet confirmed when the image was drawn. Every illustration is original flat vector art drawn in code by `tools/render.py` (Python + Pillow); `main.ts` copies the finished `entry.png` to the output directory. See `SOURCES.md` for the full story list and the consensus-vs-research notes behind it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
